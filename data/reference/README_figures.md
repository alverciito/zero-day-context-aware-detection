## Analysis choices the plan does not fix

- FIG-1 (plan §11, §5.3) The plan asks for a 'mean-rank plot' and does not fix which interval to draw. The mean rank is drawn with +-1.96 standard errors across datasets, plus the per-dataset ranks; it is descriptive, not adjusted for multiplicity, and replaces no test. No critical-difference diagram is drawn (§5.3 rules it out with 55 pairs).
- FIG-2 (plan §14.1) The label vocabulary (CONFIRMATORIO / SENSIBILIDAD / EXPLORATORIO) has no label for the secondary metrics of §3.2 (calibrated F1, WindowDiff) nor for the cost of §9. '[SENSIBILIDAD plan §3.2 ...]' and '[CONFIRMATORIO plan §9 ...]' are used with an explicit qualifier, always with one of the three prefixes of §14.1.
- FIG-3 (plan §3.6) The smoothed trivial F1 line of the appendix figure, and the count of bars below it, come from an audit made before the plan was frozen, so they are labelled [EXPLORATORIO] even though they accompany figures of the original submission.
- FIG-4 (plan §9.5) The plan asks for the records per second of the post-processing stage (KMD, MVD, filters, fusion, threshold). timing.json does not separate that stage: 'timing.total_s' of metrics.json is reported, which includes every sensitivity analysis, and it is declared in the caption as an upper bound.
- FIG-5 The full main table (9 datasets x 11 configurations x 3 metrics) does not fit on one page: it is generated as a longtable (requires \usepackage{longtable}) and also as a compact one-page version with ROC-AUC only.
- FIG-6 (plan §4.5) An output built from inputs other than the final aggregate and its statistics carries the label [PARTIAL INPUTS]. The outputs generated from the shipped data read the final inputs and do not carry it.
- FIG-7 (plan §11 R1.10) The 'best-performing configuration per dataset' table the plan asks for is generated as `tab_best_per_dataset.tex`, with the literal note 'selected on evaluation results; descriptive, not an estimate of expected performance' in the caption and as a LaTeX comment, plus AUC_t and the number of seeds per row. Selection on the evaluation segment remains excluded from the abstract, the highlights and the contributions (§11).

## Using the outputs

- Every figure `.tex` is a self-contained `figure*` that includes `figures/<name>.pdf`. The `.png` files are raster copies of the same figures.
- The tables need `\usepackage{booktabs}`; `tab_main_results.tex` also needs `\usepackage{longtable}` (one-page alternative: `tab_main_results_compact.tex`).
- Every value printed by these outputs is listed in `numbers_used.md` with the pointer to its source.
